# IF0010-Proyecto-Facturacion-Grupo-2
Título del proyecto: Sistema de Facturación

Descripción general
Sistema de facturación para la empresa ficticia Soluciones Magníficas S.A., dedicada exclusivamente a la venta de productos de supermercado. Está desarrollado en SQL Server e incluye una base de datos para gestionar clientes (personas físicas y jurídicas), productos y facturas, con procedimientos almacenados, auditoría de cambios y control de acceso por roles. Fue elaborado para el curso IF0010 Bases de Datos II de la Universidad de Costa Rica.
